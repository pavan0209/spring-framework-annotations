# 🚀 Spring Framework Annotations

A curated collection of practical examples illustrating how Spring Framework annotations simplify bean creation, dependency injection, and configuration in Java applications.

---

## 📚 What This Covers

✔ Dependency Injection  
✔ Bean Creation & Management  
✔ Component Scanning  
✔ External Property Injection  
✔ Java-based Configuration  
✔ Multiple Bean Handling  

---

## ⚙️ How It Works

| Annotation | Description |
|-----------|-------------|
| `@Component` | Creates a Spring-managed bean automatically |
| `@ComponentScan` | Scans packages for Spring components |
| `@Autowired` | Injects dependency automatically |
| `@Qualifier` | Selects a specific bean when multiple beans exist |
| `@Primary` | Sets default bean for injection |
| `@Bean` | Manually creates and registers a bean |
| `@Configuration` | Defines Java-based Spring configuration |
| `@Value` | Injects value into fields |
| `@PropertySource` | Loads values from external properties file |
